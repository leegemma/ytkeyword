🔑 YouTube API 키 설정

YouTube Data API v3

영상 검색에 필요한 키입니다. 키는 이 브라우저의 localStorage에만 저장되고, 외부 서버로 전송되지 않습니다.

발급: Google Cloud Console → API 및 서비스 → 라이브러리 → "YouTube Data API v3" 사용 설정 → API 키 만들기

Gemini API (영상 요약용 · 선택)

✨ "요약" 버튼으로 영상을 Gemini AI가 분석하게 하려면 필요합니다. 무료 발급 가능.

발급: Google AI Studio → "Create API key"

💾 데이터 백업 / 복원

검색 기록 · 저장한 영상/채널 · 차단 목록 · 설정을 JSON 파일로 백업합니다. 브라우저 기록을 지우거나 다른 기기에서 쓸 때 복원하세요. 캐시(요약/종횡비)는 제외되어 파일이 가볍습니다.

덮어쓰기: 현재 데이터를 백업 파일 내용으로 교체 · 병합: 백업의 저장/차단/기록을 현재 데이터에 추가 (중복 자동 제거)

☁️ GitHub Gist 클라우드 동기화

GitHub 계정으로 데이터를 비공개 Gist에 저장해 다른 기기·브라우저에서 불러올 수 있습니다.

발급: GitHub Settings → Tokens (classic) → gist 권한만 체크 → Generate token
