# ytkeyword

YouTube 키워드 분석 도구. 키워드로 영상을 검색하고 **구독자 대비 조회수(성과 배수)**, **기여도**, **노출 확률** 5단계 뱃지로 평가.

## 로컬 실행

```bash
python3 -m http.server 8000
```

http://localhost:8000 접속.

## 라이브

https://leegemma.github.io/ytkeyword/

## API 키 발급

1. https://console.cloud.google.com → 프로젝트 생성
2. API 및 서비스 → 라이브러리 → "YouTube Data API v3" → 사용 설정
3. 사용자 인증 정보 → API 키 만들기 → 키 복사
4. 사이트 우상단 "🔑 API 키" → 붙여넣기

키는 **각 사용자 브라우저의 localStorage**에만 저장됨. 코드/repo에 박히지 않음.

## 점수 알고리즘

- **성과 배수** = 영상 조회수 / 채널 구독자수
- **최신 성과도** = 성과 배수 / 경과일
- **기여도** = 영상 조회수 / (채널 총 조회수 / 채널 총 영상수) — 평균 영상 대비 몇 배인지
- **노출 확률** = (좋아요 + 댓글) / 조회수 × 100 (참여율 %)

| 뱃지 | 성과도 | 기여도 | 노출 확률 |
|------|--------|--------|----------|
| Worst | < 0.3x | < 0.3x | < 0.5% |
| Bad | 0.3 ~ 1x | 0.3 ~ 1x | 0.5 ~ 1.5% |
| Normal | 1 ~ 3x | 1 ~ 3x | 1.5 ~ 4% |
| Good | 3 ~ 10x | 3 ~ 10x | 4 ~ 8% |
| Great | 10x+ | 10x+ | 8%+ |
